# Language convention

## German

- Default: proper Umlaute (ä, ö, ü, ß) - never ae/oe/ue/ss
- Exception: commit messages use ae/oe/ue/ss ASCII substitutes instead
- Applies to: GitHub issues (titles, bodies, comments - map, tickets, resolution comments, everything on the tracker), Markdown meant for the end user (`README.md`, `CONTEXT.md`, `docs/adr/`, `docs/*.md` describing the product/domain), and everywhere else German text appears

## English

- Code comments (`.go`, `.html`, any other source file) - regardless of the language used elsewhere in the ticket/commit for that change
- Markdown internal to development/tooling: `AGENTS.md`, `CLAUDE.md`, `docs/agents/`
