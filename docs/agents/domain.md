# Domain docs

Single-context repo. Before working on an area:

- Read `CONTEXT.md` (glossary) and the ADRs in `docs/adr/` that touch the area.
- Use the glossary's terms in issue titles, tests and proposals, not synonyms it avoids. A missing term means either invented language (reconsider) or a gap (note it for `/domain-modeling`).
- If your output contradicts an ADR, say so explicitly ("Contradicts ADR-0007, but worth reopening because ...") instead of overriding it silently.
